----Data Story----
The purpose of this project is to inform the Australian consumers of television on which model is the most suitable across every factor. The data visualized in the project aims to further draw interest from the target audience.

----About the Data----
The data was obtained from data.gov.au under "Energy Rating Data for household appliances – Labelled Products" and "Televisions".
The data was processed to exclude columns with missing data and restructured to match the goals of this project.
The data obtained can be publicly accessed through the data.gov.au website of the Australian Government, and all data used were inputted anonymously by consumers.
The accuracy of the data solely depends on the information gathered by those involved with the Australian Government, and any other limitations include human error.
